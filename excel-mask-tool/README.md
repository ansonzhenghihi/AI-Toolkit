# 数据脱敏工具 · 使用说明

> 读者：需要把人员台账、司机资料等对外分享的运营 / HR / 行政，以及需要扩展脱敏规则的同学。
> 目的：两件事——① 日常一键脱敏；② 把 xlsm 交给 AI 扩充新的脱敏格式。

文件：`数据脱敏工具.xlsm`（Excel 宏工作簿，需启用宏）

---

## 一、用法 1：执行脱敏

### 1. 打开
双击 `数据脱敏工具.xlsm` → 如顶部提示「安全警告」，点「启用内容」。

界面只有三行输入 + 两个按钮：

| 位置 | 内容 |
|---|---|
| A3 源文件 | 待脱敏文件路径（自动填） |
| A4 输出目录 | 默认与源文件同目录 |
| A5 状态 | 完成后显示「脱敏 N 格 + 输出路径」 |
| I3 | 【选择文件】按钮 |
| A7 | 【执行脱敏】按钮 |
| A9 起 | 处理日志（逐列显示识别结果） |

### 2. 操作
1. 点【选择文件】，选 `.xls / .xlsx / .xlsm`（想先试效果可选自带的 `Demo-示例公司员工信息表.xlsx`）
2. 点【执行脱敏】
3. 同目录生成 `原名_脱敏_YYYYMMDD_HHNNSS.xlsx`（**无宏**，可直接外发）
4. 看日志确认：每行 `[Sheet 名] 表头第 N 行：列名→类型(数量)`

> Demo 预期结果：28 格被脱敏、sheet 名变 `﹡﹡公司人员档案`、输出文件名变 `Demo-﹡﹡公司员工信息表_脱敏_….xlsx`。

### 3. 安全边界
- 源文件 **只读打开**，哈希与修改时间不变
- 每个 sheet 都处理；输出为副本，格式、列宽、合并单元格保留
- 空单元格跳过；表头行以上内容不动
- 表头自动识别（前 20 行按关键字打分，≥2 命中取最高行），不识别则回退首个非空行并写日志

### 4. 默认脱敏规则

| 类型 | 识别表头关键字 | 效果示例 |
|---|---|---|
| 身份证 | 身份证,身份证号,身份证号码,公民身份号码 | 1990111111111111 → `19***********111` |
| 证件 | 从业资格证,资格证,驾驶证,执业证,证书编号,证号 | 同身份证 |
| 电话 | 电话,手机,联系电话,联系方式,座机,手机号 | 13800000000 → `138******00` |
| 卡号 | 卡号,银行卡,IC卡,社保卡,账号 | 6222000000000000000 → `62***************00` |
| 姓名 | 姓名,名字,押运员,驾驶员,司机,员工,联系人,负责人 | 张三 → `张某` |
| 公司 | 公司,单位,企业,集团,事务所 | 示例物流有限公司 → `******公司` |
| 住址 | 住址,地址,居住地址,户籍地址,现住址,家庭住址,联系地址 | 广东省某市某区某路1号 → `广东省********` |

- 识别优先级：**身份证 > 卡号 > 证件 > 电话 > 公司 > 姓名 > 住址**
- 表头含 `单位/公司/机关/类别/类型/名称/证书` 不会被判为「姓名」
- 未命中任何类型的列 **原样保留**（如发证机关、入职时间、代码）
- 字符串长度 ≤ 保留前+后 时，整串替换为掩码字符，避免短串泄露

### 5. 文件名与 sheet 名
- 输出文件名、各 sheet 名中的公司名同样脱敏：`示例公司员工信息表.xlsx` → `﹡﹡公司员工信息表_脱敏_….xlsx`
- 用 `﹡`（U+FE61）而非 `*`：Windows 文件名与 Excel sheet 名都禁止半角 `*`
- sheet 重名会自动追加 `_2`、`_3`

### 6. 调整规则（无需改代码）
在「规则配置」sheet 直接改，**改完立即生效**：

| 列 | 含义 |
|---|---|
| A 类型 | 身份证 / 证件 / 电话 / 卡号 / 姓名 / 公司 / 住址（可新增） |
| B 表头关键字 | 逗号分隔，中英文逗号均可 |
| C 保留前 / D 保留后 | 保留字符数，中间用掩码字符补齐 |
| E 掩码字符 | 一般为 `*`，姓名用 `某` |
| F 启用 | 填「否」即停用该规则 |

> 姓名 / 公司 / 住址 为特殊规则，C、D 两列被忽略（分别固定为「保留姓」「保留结尾公司」「保留到省市区」）。

## 二、用法 2：把 xlsm 交给 AI，增加新的脱敏格式

适合：出现新字段（如银行卡、邮箱、车牌、护照号）或新的脱敏样式，不想手写 VBA。

### 1. 先判断属于哪一类

| 情况 | 需要改什么 |
|---|---|
| 只是新字段名，掩码方式＝「保留前后 N 位」 | **只加一行配置**，不用改代码 |
| 需要特殊样式（如邮箱保留 @ 后域名、车牌保留省份简称） | 加配置行 + 在 VBA 模块 `M_Mask` 增加一个掩码函数与分支 |

### 2. 交给 AI 的三样东西
1. `数据脱敏工具.xlsm`
2. 需求描述（示例值 + 期望结果，越具体越好）
3. 一句话说明属于上表哪一类

### 3. 可直接复制的提示词

```
这是 Excel 数据脱敏工具（含 VBA 模块 M_Mask，规则在「规则配置」sheet）。
请新增一种脱敏类型：
- 类型名：邮箱
- 识别表头关键字：邮箱,电子邮箱,邮件地址,email
- 示例：zhangsan@abc.com → ****@abc.com
- 掩码方式：保留 @ 后的域名，@ 前用 * 替换
- 优先级放在「电话」之后

要求：
1. 在「规则配置」追加一行，保持与现有行同样的字体、行高、边框
2. 在 M_Mask 模块参照现有 MaskName / MaskCompany 的写法新增函数，并在 ApplyMask 中加分派支路
3. 不改动其他规则与前端界面
4. 完成后用样例文件跑一次，把日志贴给我
```

### 4. AI 需要开启的权限
改 VBA 代码需要「信任对 VBA 工程对象模型的访问」：

- 手动：`文件 → 选项 → 信任中心 → 信任中心设置 → 宏设置 → 勾选「信任对 VBA 工程对象模型的访问」`
- 或由 AI 临时写注册表 `HKCU\Software\Microsoft\Office\16.0\Excel\Security\AccessVBOM = 1`，改完还原
- 仅改「规则配置」sheet 时**不需要**这个权限

### 5. 验收清单
| # | 检查项 |
|---|---|
| 1 | 新规则出现在「规则配置」，原有 7 行未变 |
| 2 | 日志里能看到 `新列名→新类型(N格)` |
| 3 | 单元格值与预期完全一致（含短串、空值） |
| 4 | 其他列、其他 sheet 未被误改 |
| 5 | 输出文件无宏、可正常打开 |
| 6 | 源文件哈希未变 |

### 6. 已知注意点
- 代码中的中文字符串必须用 **UTF-8（无 BOM）** 的 `.bas` 通过 `VBComponents.Import` 导入；用 `AddFromString` 分批写入会出现行序错乱导致宏不可用
- 掩码后的值写回前会把整列设为文本格式（`@`），避免电话、长数字变成科学计数
- 超过 15 位的数值单元格会按显示值处理并写日志提示（原表该列建议设为文本）

## 三、常见问题

| 现象 | 原因 / 处理 |
|---|---|
| 打开后按钮无反应 | 宏被禁用：点「启用内容」或把文件放到受信任位置 |
| 某列没脱敏 | 表头没命中关键字：在「规则配置」补关键字，或按用法 2 扩展 |
| 输出文件名带 `﹡` | 正常：文件名 / sheet 名禁止半角 `*` |
| 电话变成 1.39E+10 | 只在旧版本出现；当前版本写入前已转文本 |
| 日志提示「表头识别置信度低」 | 表头不在前 20 行或关键字太少，检查源表表头 |

## 四、文件结构

```
excel-mask-tool/
├─ 数据脱敏工具.xlsm                  ← 工具本体（前端 + 规则 + VBA）
├─ README.md                          ← 本文件
├─ Demo-示例公司员工信息表.xlsx         ← 虚构数据 Demo（可直接试跑）
├─ Demo-﹡﹡公司员工信息表_脱敏_….xlsx   ← Demo 的输出样例（无宏）
└─ docs/Excel数据脱敏工具实现计划.md     ← 设计与实现记录（构建脚本、验证清单）
```

Demo 数据全部为虚构：姓名、身份证、电话、卡号、地址均不对应真实个人；含「所属公司」列，用于演示公司名与文件名/sheet 名脱敏。

| sheet | 作用 |
|---|---|
| 脱敏工具 | 前端：选文件、执行、看日志 |
| 规则配置 | 脱敏规则表（可改可加） |
| 模块 M_Mask | 全部逻辑：`RunMask` 主流程、`PickFile` 选文件、`MaskKeep / MaskName / MaskCompany / MaskAddress` 掩码函数 |

版本：2026-11 · 支持 身份证 / 证件 / 电话 / 卡号 / 姓名 / 公司 / 住址 七类，含文件名与 sheet 名脱敏。
