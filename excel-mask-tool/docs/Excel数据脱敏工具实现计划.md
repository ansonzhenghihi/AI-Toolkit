## 四、工具设计

### 4.1 前端 sheet「脱敏工具」

```
A1:J1  数据脱敏工具（合并标题）
A3  源文件      B3:H3  [路径]              I3  [选择文件] 按钮
A4  输出目录    B4:H4  [默认=源文件目录]
A5  状态        B5:H5  空闲
A7  执行脱敏 按钮（Forms 按钮，OnAction=RunMask）
A9 起：处理日志（逐行追加：时间 / sheet / 识别列 / 行数 / 结果）
```

表格行数（表头行）不在前端暴露，一律后台自动识别。

说明区固定文案：源文件不会被修改；输出为无宏 xlsx。

### 4.2 配置 sheet「规则配置」（可改，改完即生效）

| 类型 | 表头关键字（逗号分隔） | 保留前 | 保留后 | 掩码字符 | 启用 |
|---|---|---|---|---|---|
| 身份证 | 身份证,身份证号,身份证号码,公民身份号码 | 2 | 3 | * | 是 |
| 证件 | 从业资格证,资格证,驾驶证,执业证,证书编号,证号 | 2 | 3 | * | 是 |
| 电话 | 电话,手机,联系电话,联系方式,座机,手机号 | 3 | 2 | * | 是 |
| 卡号 | 卡号,银行卡,IC卡,社保卡,账号 | 2 | 2 | * | 是 |
| 姓名 | 姓名,名字,押运员,驾驶员,司机,员工,联系人,负责人 | 1 | 0 | 某 | 是 |

匹配规则：
- 识别顺序：身份证 → 卡号 → 证件 → 电话 → 姓名（先精确长词，避免「证」误配）
- 排除词：表头含 `单位/公司/机关/类别/类型/名称` 不匹配姓名
- 未命中任何类型的列：原样保留

### 4.3 脱敏函数

```
MaskKeep(s, front, back, maskChar):
  s = Trim(原始文本)                      ' 数字先转字符串，禁止科学计数
  L = Len(s)
  若 L <= front+back → 全文替换为 maskChar × L（防短串泄露）
  否则 → Left(s,front) + maskChar × (L-front-back) + Right(s,back)

MaskName(s):
  姓 = Left(s,1)；其余每个字替换为「某」    ' 陈栋任 → 陈某某；李文全 → 李某全? → 李某某
```

姓名口径定为：保留首字，其余逐字替换（2 字名 → 李某；3 字名 → 李某某）。示例「李某」两解均满足，按更常见做法取逐字。

### 4.4 VBA 结构（`M_Mask.bas`，过程名英文、界面文案中文）

| 过程 | 职责 |
|---|---|
| `RunMask` | 主流程：校验路径 → 读配置 → 打开源（ReadOnly）→ 定位表头 → 逐 sheet 识别列 → 掩码 → 写新工作簿 → 保存 xlsx → 日志 → 关闭源不保存 |
| `PickFile` | `Application.FileDialog` 选 .xls/.xlsx/.xlsm，回填 B3 |
| `FindHeaderRow(ws)` | 前 20 行按关键字命中数打分，取最高行（≥2 命中）；识别失败则回退到首个非空行，并写日志 |
| `MapColumns(ws, headerRow)` | 返回 列号→类型 的映射 |
| `ReadCellText(c)` | 数字 → `Format(v,"0")`；文本 → `Value`；空 → `""` |
| `MaskKeep` / `MaskName` | 纯函数，无副作用 |
| `WriteLog(msg)` | 追加到前端 A10 起 |

关键实现约束：
1. **数字列先取文本**：`IsNumeric` 且长度 ≤15 用 `Format(v,"0")`；>15 位取 `.Text`（防精度丢失），并在日志告警。
2. **输出列设为文本**：写入前把目标列 `NumberFormat = "@"`，避免 `*` 串被转换、避免 11 位电话变科学计数。
3. **批量数组**：每 sheet 读入 Variant 数组 → 内存处理 → 一次性赋值，避免逐格写。
4. **只处理表头行以下**、跳过全空行。
5. **输出为复制后的新工作簿**：`ws.Copy` 到新 workbook 以保留格式/列宽/合并，然后覆盖脱敏列；保存为 `.xlsx`（`FileFormat:=51`）。
6. `DisplayAlerts=False`，异常用 `On Error GoTo` 统一收尾（关闭工作簿、释放对象、写日志）。

## 五、实现步骤

1. 临时把 `HKCU\Software\Microsoft\Office\16.0\Excel\Security\AccessVBOM` 置 1。
2. `%TEMP%` 下写构建脚本（Python + pywin32）：新建工作簿 → 建「脱敏工具」「规则配置」两 sheet 并布局 → 写入 `M_Mask.bas` → 加按钮 → 另存 `数据脱敏工具.xlsm`。
3. 还原 `AccessVBOM`（无原值则删除该项）。
4. 用示例 `.xls` 跑一次，核对输出。
5. 校验源文件哈希未变，清理临时脚本。

## 六、假设与决策

- 姓名只处理单字姓（复姓按首字保留，如「欧阳」→「欧某某」）——不额外做复姓词表。
- 「住址」「发证机关」「有效期」不在脱敏范围，原样保留。
- 一次处理一个文件；多 sheet 全部处理。
- 自动识别表头（前 20 行按关键字打分），识别失败回退首个非空行并在日志告警；前端不展示、不需手填。
- 输出文件名固定带时间戳，重复执行不覆盖历史结果。
