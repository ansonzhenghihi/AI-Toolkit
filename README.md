# AI-Toolkit

把日常工作里重复、易错、需要交付给非技术同事的环节，做成即开即用的工具。

## 工具清单

| 工具 | 形态 | 说明 | 目录 |
|---|---|---|---|
| Excel 数据脱敏工具 | `.xlsm`（Excel 宏） | 一键对人员台账、司机资料等表格脱敏，输出无宏副本；支持身份证 / 证件 / 电话 / 卡号 / 姓名 / 公司 / 住址七类规则，规则可在表内改 | [excel-mask-tool](./excel-mask-tool) |

## 使用方式

进入对应工具目录，按该目录下 README 操作。每个工具均包含：可执行文件、使用说明、可直接试跑的 Demo。
